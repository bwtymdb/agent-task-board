看板直接读取这台电脑上的会话状态。把正在推进的工作加上星标，就能持续关注；其他历史对话仍可在完整列表中查找。

01 / 聚合

三个平台，一处查看

集中显示 WorkBuddy、Kimi Code、Kimi Work 的本机会话，不再逐个打开平台找任务。

02 / 重点

星标决定关注对象

当前工作加入重点监控；暂时收起的会话进入归档，两种用途互不混淆。

03 / 提醒

完成与异常，声音不同

黄灯变绿灯播放柔和双音，黄灯变红灯播放警示音。初次加载不会集中发声。

04 / 操作

从看板回到工作

支持打开原对话、同步重命名和平台归档。Kimi Code 后台任务也可按需停止。

05 / 桌面

可见，也可以不打扰

支持窗口置顶、透明度调节、鼠标穿透、屏幕边缘缩略区和系统托盘。

06 / 本地

会话内容留在本机

不需要注册看板账号，不上传对话正文，不包含遥测。平台升级导致的数据变化会明确提示。

三盏灯，
各自只表示一件事。

颜色来自平台真实状态，不能手工改灯。这样看到的“进行中”，不会只是自己随手做的标记。

红灯 · 需要处理

等待权限确认、等待回答问题、执行失败，或平台状态需要人工介入。

黄灯 · 正在执行

平台正在生成回复、运行工具，或仍有其他后台任务在执行。

绿灯 · 本轮完成

当前这一轮已经结束，会话处于空闲状态，可以检查结果或继续提问。

注意：绿灯表示“这一轮结束”，不代表整个项目已经全部完成。

三步开始使用。

看板本身不需要登录。请确保电脑上已经安装并登录需要监控的 WorkBuddy、Kimi Code 或 Kimi Work。

下载安装包

点击本页下载按钮，获得 AgentTaskBoard-Setup-0.1.1.exe，无需下载整个源码目录。

双击完成安装

按照安装向导操作。安装包未购买代码签名证书，Windows 可能提示“未知发布者”。

从开始菜单启动

按 Windows 键，搜索“AI任务看板”并打开。以后也可单击右下角托盘图标显示主界面。

使用前，
还需要知道这些。

能在手机或其他电脑上同步吗？

当前版本只监控安装看板的这台 Windows 电脑，不同步手机、其他电脑或云端账号的全部会话。

三个平台的能力完全一样吗？

不完全一样。Kimi Work 当前仅纳入 Work Agent 会话，支持看板别名和打开平台，不支持平台重命名或归档。

如何持续看到最重要的工作？

在任务左侧点击星标，它会进入“重点监控”。重点任务不会因本轮完成而自动移除，由你决定何时取消关注。

软件是开源的吗？

是。项目采用 MIT 许可证，可在 GitHub 查看源码、更新日志、平台能力矩阵和已知限制。
